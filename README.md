# Maysville Missions

Maysville Missions is a web-based application designed to encourage meaningful community engagement through guided journeys, personal growth, and shared experiences.

The platform provides structured opportunities for individuals and groups to put their values into practice through manageable activities and intentional challenges. Users can discover available journeys, enroll in activities, track their progress, and participate in experiences that encourage connection and service within their communities.

## Features

### Journey Discovery
- Browse available journeys organized around personal growth, community engagement, and service.
- View journey descriptions, activities, and completion requirements.
- Explore different journey formats based on individual or group participation.

### Individual Journeys
- Enroll in and participate in guided journeys.
- Track progress through individual journey steps.
- Record completed activities and add notes.
- Monitor completion status and progress toward journey goals.
- Abandon or rejoin journeys as needed.

### Group Participation
- Support for group-based journeys.
- Group membership and participation management.
- Shared journey instances that allow participants to work toward common goals.

### Progress Tracking
- Track completion of individual journey steps.
- Support activities with multiple completion requirements.
- Record activity history and associated notes.
- Maintain journey and step completion timestamps.

### User Accounts
- Account registration and authentication.
- Secure password storage using bcrypt.
- JWT-based authentication.
- User roles supporting standard users and administrators.

## Technology Stack

The application uses a separated frontend and backend architecture.

| Layer | Technology |
|---|---|
| Frontend framework | Angular 21 |
| Frontend language | TypeScript |
| Styling | Tailwind CSS 4 |
| UI components | daisyUI 5 |
| Icons | Font Awesome |
| Backend framework | NestJS 11 |
| Backend language | TypeScript |
| API architecture | REST |
| ORM | Prisma 7 |
| Database | PostgreSQL |
| Database hosting | Neon |
| Authentication | JWT / Passport |
| Password security | bcrypt |
| Frontend hosting | Netlify |
| Backend hosting | Render |
